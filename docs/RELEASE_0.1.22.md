# CatanCraft v0.1.22 — Protected TH4/TH5 purchase-driven upgrade candidate
**FOR A SEPARATE BACKED-UP R7 SOLO TEST WORLD ONLY. NOT YET ACCEPTED IN-GAME, NOT LIVE-APPROVED.**
## Scope
- Upgrade City Level 3 -> 4 shows Blender's TH4 schematic automatically; City Level 4 -> 5 shows TH5. Uses ordinary /nation upgrade city <territory> and GUI shared command path. Charges exactly once after world placement succeeds and saves city level, nation balances and visual revision together.
- Keeps existing successful v0.1.21 R7 purchase-driven Commercial District + Logistics Center construction; no pilot commands, repeated imports or rollbacks for normal gameplay.
- Reuses existing TH4/TH5 Sponge schematics from supplied v0.1.21 kit under config/catancraft/schematics/thall4.schem and thall5.schem. Schematic selection is NOT globally switched: legacy refresh-owned-city-visuals path skips high-tier Town Halls rather than blindly repasting TH3 across them.
- SchematicPlacementService.plannedCells exposes **READ-ONLY** 75x47x65 full voxel plan (including air) and exact world 0°/180° transforms for the guarded transaction. No world writes from this API.
- New TownHallPrestigeUpgradeService does full old-tier byte-accurate voxel comparison (allowing ordinary open-door changes, leaf distance and manager lectern HAS_BOOK/POWERED); refuses any foreign edits or tiles; refuses occupied hall; blocks on no available source/destination schematics, unmatched visual source token or invalid world. Preserves real management lectern and its book/NBT **without touching its block**. Old TH3 decorative lectern must be empty.
- Writes an atomic compressed NBT before-image journal in save/data/catancraft_th_prestige_<city>_<tier>_v1.dat before any physical changes. Applies drop-suppressed writes, checks exact target blocks and preserved manager NBT, records physical-before-economy phase, makes single economy charge/level update, saves whole server then commits journal. Existing journal blocks any repeated attempt, including crash/restart unknown state. This is deliberate fail-closed, NOT an implemented automatic rollback/resume.
- Guard limited to exact R7 test world folder CatanCraft_Season1_R7_Development + internal V4/R2 LevelName + existing one-time disposable R7 marker. Never remove marker from user's working test world unless intentionally disabling autobuild. Other saved worlds are not modified.
## Known caveats / gates
- Full 229,125 voxel contract check on each upgrade may refuse even ordinary player-made decorations; this is intentional for initial test. User inventory, doors and roof need player visual acceptance.
- The older TH1->TH2->TH3 code still uses previous unjournaled schematic placement; v0.1.22 does not automatically make those tiers reversible. Missing source visual token for already-paid Level 4/5 legacy saves currently **refuses** rather than charging again; separate zero-charge retrofit is future work.
- Interrupted/power-loss transactions require a dedicated reconciliation procedure; do not delete journals, attempt another upgrade, use /catan map refresh assets, or manually paste a hall.
- No R8A/R8 full terrain acceptance implied. Current R7 world remains test-only; user has commissioned R8 transitions followed by R9 surrounding ocean. Not a live-server release.
- Developer must still verify Forge CI and end-to-end runtime test before acceptance.
