# ECO-03 — controlled low-speed vehicle departures

This extends the 048 observations with eight required departure cases: pickup and LAV-150, source orientations 0 and 180, and both road directions. Only the exact marked, no-player `controlled-catancraft_vehicle50-run/world` can stage fixtures. The unchanged 18,400-cell factory-over-starter source and existing posts/lanterns are retained. The native runtime and effective vehicle definitions retain their 046–048 pins.

The controller uses the real `VehicleMovementMessage.handler` with the actual first-passenger driver and natural server ticks. It never writes vehicle position, velocity, orientation, steering state or engine power after initial spawn setup. Its sequence is neutral observation; forward with brake for 16 blocks to the original 046 junction; a full stop; 30 ticks of stationary pre-steering with brake; alternating forward/reverse 0.65-block steering legs, each separated by a full stop and reversed pre-steering, through a 90-degree turn; heading alignment; six blocks straight along the road; and a final stop. This demonstrates one careful departure maneuver, not comfortable full-speed steering or all possible player maneuvers. Brake and steering key meanings are verified against the SHA-pinned SBW source reviewed for 048.

Every tick records the native pose, speed, energy, movement key bits, controller phase and all eight/ten native-part AABBs. Finite checks, exact native-part count, authored-envelope bounds, collision flags, source consistency, full-footprint floor support, fluids and other-entity occupancy are required. The actual driver is excluded only from external-entity occupancy. Between observations, corresponding AABB unions receive a conservative angular interpolation allowance using a separately bounded 15-block native radius and the sum of yaw/pitch/roll changes. No vehicle part or source block is exempted to make a route pass.

A required test fails on collision, unsupported/changed source, envelope escape, lost residency/driver, nonfinite geometry or the bounded tick limit. It cannot pass merely by observing propulsion/steering. Success requires completion of the maneuver, at least 80 degrees of steering change, actual energy consumption and all source cells unchanged. Failed trajectories remain JSON evidence. A route pass still does not establish production reservation, client control, every factory plot, every vehicle, or installed-pack acceptance. Production authority must use the actual qualified source/route footprint and remain held if qualification fails.

Command (root runner only): `gradle runGameTestServer -PcontrolledGameTests=true -PgameTestNamespace=catancraft_vehicle50 -Pvehicle50Source=<exact source SHA> -I tools/vehicle50/validate.gradle`. Expected required case count: **8**. This document declares assertions; actual results belong in the exact-source validation evidence.
