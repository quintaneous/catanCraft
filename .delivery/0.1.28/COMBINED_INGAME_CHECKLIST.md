# Combined 0.1.28 acceptance checklist

One JAR, one isolated single-player development copy, never the active world or installed mod directory. Retain the copy's backup and existing R7 authorization marker. This checklist is manual acceptance still to be performed; native automation does not certify TaCZ or Superb Warfare.

1. Record the owned city's paid producer/city levels, treasury, nation stockpile, management book NBT and inventories. Use an already paid tier 3–5 producer and six recognized R1/R2 houses. Keep a harmless item/entity near an unchanged plot cell.
2. As operator, run `/catan producer status a`, then `/catan producer exterior a confirm`. Check corrected solid exterior details, unchanged paid tiers/resources/inventories and preserved nearby item. Repeat: no further writes/payment. A genuine collision/support/attachment hazard must refuse with no fresh charge; do not broadly clear the plot.
3. Run `/catan r5 houses status a`, then `/catan r5 houses apply a confirm`. Inspect all six facade/roof groups, inventories and management book. Correction is free; repeat is a no-op. Modified/unrecognized whole-house sources must refuse. Do not repair source drift by overwriting player blocks.
4. As the owning nation leader, run `/nation defense list a`. Quote a compatible socket, e.g. `/nation defense quote a access_checkpoint`, review the complete cost, then `/nation defense buy a access_checkpoint confirm`. Check exactly one nation debit ($2,000, wood20, stone40), no inventory-item charge, full supports and road clearance. Requote/repeat: no additional debit or duplicate module. Check an independent casemate socket (`r6_casemate_w`: $4,000, concrete40, steel15) and short wall (`r6_west_01_half_0`: $500, wood5, stone15), respecting status/dependency refusals. No gates, trenches or rejected bunkers should be offered.
5. Save/restart this development copy once. Verify geometry, ownership, paid levels, balances, inventory/book NBT and socket status persist; no new modules install automatically. Use journaled `resume ... confirm` for an interrupted operation; do not delete journals or manually refund a usable partial defense. A rollback with drift/dependents must refuse rather than erase inventory or other purchases.
6. Visually inspect roof/facade lighting, TaCZ firing apertures and Superb Warfare pickup/LAV clearances using the intended development modpack. Record exact observed failures and logs. These checks remain manual; no multiplayer tests are included. Crowbar exploit remains **UNRESOLVED / HIGH PRIORITY**.

Substitute the actual owned city ID for `a`. Do not roll back accepted Town Hall/public-space work, perform all-city terrain rollout, or deploy to a live server as part of acceptance.
